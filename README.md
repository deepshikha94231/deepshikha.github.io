# Deepshikha Urmaliya — Academic Homepage

A responsive static academic portfolio website built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — page content and structure
- `styles.css` — design and responsive layout
- `script.js` — mobile menu and footer year
- `assets/cv.pdf` — add your CV here

## Personalize before publishing

1. Replace `your.email@iith.ac.in` with your real academic email.
2. Replace the Google Scholar, GitHub, and LinkedIn placeholder links.
3. Add your profile photograph by replacing the `portrait-placeholder` in `index.html` with an `<img>` element.
4. Replace the publication/project placeholders with your actual work.
5. Add your CV as `assets/cv.pdf`.
6. Update the institute/department/supervisor details if desired.

## Publish with GitHub Pages

1. Create a GitHub repository named `yourusername.github.io`.
2. Upload all website files while preserving the `assets` folder.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main`, and save.
5. Your site will be available at `https://yourusername.github.io/`.

No build system or npm installation is required.
